# 🌍 WanderWorld – Travel Website

## 📌 Project Overview

WanderWorld is a modern and responsive travel website homepage developed using HTML and CSS. This website helps users explore popular travel destinations, discover hotels, and find exciting travel activities.

The main objective of this project is to create an attractive and user-friendly travel website with a clean layout and responsive design.

## 🎯 Features

- 🏠 Home Page with attractive hero section.
- 🔍 Travel destination search section.
- 🌍 Popular destinations with images.
- 🏨 Popular hotels section.
- 🎯 Popular activities section.
- 📱 Responsive design for mobile, tablet, and desktop.
- 🎨 Modern and attractive user interface.
- 🔗 Navigation menu for easy browsing.
- 📌 About section and footer.

## 💻 Technologies Used

- HTML5 – For creating the website structure.
- CSS3 – For styling and designing the website.
- CSS Flexbox and Grid – For layout design.
- CSS Media Queries – For responsive design.
- Unsplash – For travel images.


## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file.
4. Right-click and select Open with Live Server.
5. The WanderWorld website will open in your browser.
